# Expense Vault

SMBCカードのCSV明細を取り込み、支出をカテゴリ・サブカテゴリ別に集計するローカルWebアプリです。

`index.html` をブラウザで直接開いて使用します。サーバーや外部通信は不要です。データはブラウザのIndexedDBへ保存されます。

## 主な機能

- 確定CSV・未確定CSVの取込
- 月次集計
- 開始月から終了月までの期間集計
- 全合計・カテゴリ別合計・サブカテゴリ別内訳
- 親カテゴリ単位の円グラフ
- 過去の手動分類履歴による自動分類
- 常に手動分類する店舗ルール
- 未分類明細の赤色強調
- チェックボックス選択による一括分類
- 1明細を複数カテゴリへ金額按分
- 金額表示のモザイク切替
- カテゴリ・サブカテゴリの追加、名前変更、削除
- JSONバックアップ・復元

## CSV形式

最初に見つかった明細行のカラム数で形式を判定します。明細行は1列目が実在する日付として解析できる行です。

### 確定明細

7カラムとして判定し、次の列だけを使用します。

|  列 | 内容     |
| --: | -------- |
|   0 | 利用日   |
|   1 | 利用店名 |
|   2 | 利用金額 |

例:

```csv
2025/04/30,ＡｍａｚｏｎＰａｙ提携サイト,1980,１,１,1980,ＡＭＺ＊ＭＡＮＤＡＲＡＫＥ
```

### 未確定明細

13カラムとして判定し、次の列だけを使用します。

|  列 | 内容     |
| --: | -------- |
|   0 | 利用日   |
|   1 | 利用店名 |
|   6 | 利用金額 |

例:

```csv
2026/7/26,ＡＭＡＺＯＮ．ＣＯ．ＪＰ,ご本人,1回払い,,'26/08,1312,1312,,,,,
```

UTF-8とShift_JISを受け付けます。CSV先頭にある本名・カード番号・ヘッダーなど、最初の明細行より前の内容はIndexedDBへ保存せず、バックアップにも含めません。元CSVそのものも保存しません。

## 再取込時の動作

### 未確定CSVの再取込

CSVに含まれる月の未確定データを新しいCSV内容で置き換えます。

次の3項目が完全一致する明細は、既存の分類状態に応じて次のように処理します。

- 利用日
- 利用店名
- 金額

分類済みの明細は既存の分類・サブカテゴリ・按分をそのまま引き継ぎます。不明の明細は、常に手動分類する店舗ルールと過去の手動分類履歴で再分類します。再分類できた場合は自動分類を適用し、できなかった場合は不明のままです。

レコードの並び順は一致判定に使用しません。同一内容の明細が複数ある場合は件数単位で対応させます。

### 確定CSVの取込

CSVに含まれる月の未確定・確定データを確定CSV内容で置き換えます。完全一致した明細は上記と同じ規則で引き継ぎ・再分類します。

店舗名の全角・半角や表記が変わった場合は別店舗として扱います。結び付かなかった明細は、自動分類または不明になります。

## 自動分類

自動分類は同じ店舗名の過去履歴から決定します。

学習対象は次の条件をすべて満たす明細だけです。

- ユーザーが手動分類した
- 単一カテゴリへ分類されている

同じ店舗で複数の分類が使われている場合は最頻分類を使用します。同数の場合は不明にします。自動分類された明細や按分明細は学習元にしません。

「常に手動分類する店舗」のルールに一致した新規明細は、自動分類せず要手動として表示します。再取込時に完全一致した既存明細は、設定済み分類を引き継ぎます。

## 按分

明細編集画面で按分行を追加し、カテゴリ・サブカテゴリ・金額を設定します。按分合計が元明細金額と一致する場合だけ保存できます。

「均等按分」を押すと、端数を最後の行へ寄せて均等に分割します。

## 金額のモザイク

ヘッダーの「金額をモザイク」ボタンで、合計・カテゴリ集計・サブカテゴリ集計・不明金額・円グラフの凡例・明細一覧の金額を伏せ字に切り替えます。円グラフの大きさと凡例の割合（％）はそのまま表示されます。

按分編集画面の各按分行の入力欄は編集対象のため、モザイクの対象外です。

## バックアップ

バックアップには次を含みます。

- 明細
- カテゴリ
- サブカテゴリ
- 常に手動分類する店舗ルール

復元時は既存データをすべて置き換えます。
